# Teaching code playground

This web app shows a textbox in which the user can write code (C, C++, Rust, Java, Lisp, Haskell, etc.). The tool automatically detects the language. When clicking on the button "Run", the backend takes the code and compiles it and show then the result of the console back in another textbox in the html.

The idea of the tool is to be simple, neat, to show some code that we modify interactively with students during a lecture.

## Features

- Run easily small terminal programs
- Language supported: C, C++, Rust, Java, Lisp, Haskell
- Detect the language of some code


## Run the tool

You need to clone the repository locally and to run `python app.py`.
